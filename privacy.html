Little Cloud Garden Privacy Policy

Developer: Doli Rioniari.

The game does not collect, transmit, sell, or share personal data. It has no accounts, advertising, analytics, tracking, in-app purchases, or third-party software development kits.

All puzzles, pictures, music, and sounds are bundled with the app. The game does not need an internet connection to play. Music and sounds are generated on the device.

Game progress and sound settings are kept only in memory for the current visit. The app uses a non-persistent web data store. It does not deliberately save game progress, cookies, or web storage to disk. Ending the app's process starts a new visit next time. The installed application files remain on the device until the app is removed.

The app does not request your name, age, location, contacts, photos, camera, microphone, or tracking permission. It has no chat, user-generated content, or links to outside websites in the game.

Apple may process App Store transactions or operating-system diagnostics under Apple's own policies. Those services are separate from data collection by this game.

For support, use the App Support link on the game's App Store page. Contacting support happens outside the game; choose what information you send and do not include a child's personal information.

Because the game collects no personal data and has no accounts, there is no game profile or game data held by the developer to access or delete.

This policy applies to Little Cloud Garden version 1.0. Any change to the game's data practices will require an updated policy.

This website and optional support

This website is separate from the game. It contains no analytics scripts, advertising, forms, or tracking code added by the developer. GitHub Pages provides hosting and may process standard web-request information under the GitHub privacy statement.

If you choose to open a support issue, your GitHub username and message are public on GitHub. Support is intended for parents, guardians, and adult players. Do not include children's personal information, passwords, tokens, or other private information. These voluntary messages happen outside the game; the game itself does not send them.

Use the support page for troubleshooting and the public issue link.
